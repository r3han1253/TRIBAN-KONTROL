# Banka logoları

Bu klasöre her bankanın logosunu, IBAN'daki 5 haneli banka koduyla adlandırılmış PNG dosyası olarak koyun.

Örnekler:

- `00010.png` → T.C. Ziraat Bankası
- `00046.png` → Akbank
- `00062.png` → Türkiye Garanti Bankası
- `00064.png` → Türkiye İş Bankası
- `00067.png` → Yapı ve Kredi Bankası

Tüm kodlar `index.html` içindeki `BANKALAR` listesinde yer alıyor. Logosu olmayan bankalar için sayfa, baş harflerden oluşan bir rozet gösterir.
